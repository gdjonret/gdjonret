## 🚀 What I'm Working On

### Lunar Crescent Imaging for Nanosatellites

Developing an onboard image-processing pipeline designed to operate on resource-constrained satellite hardware.

Current work includes:

* 🌙 Lunar crescent detection using **YOLOv8**
* 🎯 Crescent-aware image quality assessment
* 🖼️ Multi-frame registration and image fusion
* 🌑 Low-light and dark-side lunar enhancement
* 📊 Image quality evaluation using **PSNR, SSIM, SNR, sharpness, and contrast**
* ⚡ Edge deployment and optimization on **NVIDIA Jetson Orin Nano**
* 📦 Resource-aware image processing and compression

**Tech:** Python · OpenCV · PyTorch · YOLOv8 · NumPy · GStreamer · NVIDIA Jetson
